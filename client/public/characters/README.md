## Recommended Specifications
- **Format**: Transparent PNG or WebP with alpha channel.
- **Dimensions**: 800 × 1000 px or higher (aspect ratio ~4:5).
- **Framing**: Waist-up or half-body composition.
- **Style**: Hand-drawn comic book aesthetic with expressive ink linework, crosshatching, or watercolor shading.

*Note: If any custom file is not present, the system automatically falls back to the built-in artistic comic-book vector illustration so the site never breaks or shows missing images.*
